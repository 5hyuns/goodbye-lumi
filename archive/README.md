# archive

Documents from the contest period (August to September 2026), kept as a
record of how the game was made. **They are not maintained.** File names,
sizes, line numbers and progress notes in them describe the project at the
time they were written, and many no longer match the code. For the current
state, read `docs/FILEMAP.md` and `CLAUDE.md`.

| File | What it was |
|---|---|
| `LUMI_FPS_구현명세서_v1.md` | The first implementation spec (Korean). It was written for a game of 35 to 50 minutes and for files that were never created (`data/*.json`, deck plan v7). The shipped design is in `story/*.json` |
| `AI_작업카드.md` | Prompts for working session by session with an AI assistant, written to go with the spec above (Korean) |
| `contest-status-2026-09-03.md` | The progress board the day before the deadline: what was done, what was left, what was measured (Korean) |
| `native-port-handover.md` | Notes on what had been ported from the browser previz to C and what had not, as of 2026-09-03 |
| `contest-submission-blurb.md` | The game description written for the contest entry page (English and Japanese) |
| `PROJECT_INDEX-2026-09.md` | The old hand-written symbol map. Replaced by `docs/FILEMAP.md` and `docs/symbols.json` |
