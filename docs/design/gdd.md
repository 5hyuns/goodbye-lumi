# 침몰하는 함선 (가제) — 게임 기획 문서

버전: v6 기준 / 작성일: 2026-08-28
장르: 1인칭 SF 호러 슈터 (짧은 단일 미션)
플레이타임 목표: 15~20분

---

## 1. 한 줄 요약

죽어가는 우주 함선에서 깨어난 주인공이, 파트너 로봇의 안내를 받아 함선 곳곳에 흩어진 에너지팩 3개를 회수해 마지막 남은 탈출 캡슐을 가동하고 탈출한다.

## 2. 핵심 제약

- 전체 용량 1.44MB 이내. 에셋만이 아니라 엔진/런타임을 포함한 실행파일 전체 기준.
- 네이티브 실행파일. 웹이나 기존 상용 엔진이 아님.
- 3D. 캐릭터·무기·프랍이 단순 박스로 보이지 않아야 함 — 어둠·안개·실루엣·조명으로 형태감을 만드는 방향.
- 짧고 단순한 미션 구조. 슈팅과 분위기가 중심.

## 3. 톤 앤 무드

미래지향적 슬릭 SF. 아날로그·레트로가 아니라 매끈하고 정제된 첨단 함선이다: 이음새 없는 패널 벽, 벽과 바닥을 따라 흐르는 발광 라이트 스트립, 홀로그램 안내 표시와 반투명 디스플레이, 유리와 무광 금속의 대비. 공포는 이 정제된 시스템이 죽어가는 데서 나온다 — 홀로그램이 지직거리며 왜곡되고, 라이트 스트립이 구간 단위로 꺼지고, 비상 모드의 붉은 라인만 남은 복도. 깨끗했던 공간일수록 핏자국과 파손이 더 이질적으로 보인다.

어둠은 미학인 동시에 기술 전략이다. 짙은 안개로 가시거리를 줄이면 원거리 디테일이 필요 없고, 발광 스트립과 홀로그램은 라이팅 계산 없는 이미시브 지오메트리라 극히 싸다. 텍스처 없이 버텍스 컬러 + 이미시브 라인 + 소수의 동적 조명으로 표면이 성립한다. 1.44MB에서 슬릭 SF가 오히려 레트로보다 유리한 이유 — 매끈한 표면은 디테일 텍스처를 요구하지 않는다.

## 4. 서사

- 주인공은 승무원 숙소에서 깨어난다. 함선에는 괴생명체가 퍼져 있고 승무원은 보이지 않는다.
- 탈출 갤러리에 도착하면 사출 베이 6개 중 5개가 이미 사출된 채 해치만 열려 있다 — 대사 없이 "모두 떠났고 너만 남았다"를 전달하는 장면.
- 마지막 남은 캡슐은 고장 상태. 슬롯 6개 중 3개만 점등, 3개가 공석이다. 누군가 먼저 채우다 실패한 흔적.
- 서사는 전부 환경으로만 전달한다: 시체, 핏자국, 깨진 격리창, 의무실의 생명유지장치, 통신실 조난 기록. 컷신·대사 텍스트 최소화.
- 괴생명체의 기원은 설명하지 않는다. 복도의 흔적으로 암시만.

## 5. 코어 루프

1. 로비(허브)에서 로봇이 다음 에너지팩 위치를 안내
2. 좁은 통로를 따라 이동 — 격벽 자동문 단위로 구간이 나뉨
3. 목표 방에서 전투/연출과 함께 에너지팩 회수
4. 갤러리로 귀환, 슬롯에 팩 장착
5. 장착할 때마다 함선 상태가 한 단계 악화(침몰 게이지) → 다음 왕복이 다른 경험이 됨
6. 3개 장착 완료 → 카운트다운 방어전 → 사출, 엔딩

## 6. 함선 구조 (덱 플랜 v6 기준)

### 6.1 배치 원칙

- 방은 드문드문 떨어진 섬, 그 사이를 좁고 긴 통로가 잇는다. 통로 폭은 방 폭의 약 1/5.
- 모든 통로는 격벽 자동문으로 2~4구간으로 분절된다. 자동문은 (a) 문이 열리기 직전의 공포 비트, (b) 구간 = 전투 단위, (c) 사실상 공짜 오클루전 컬링, (d) 침몰 게이지에 따른 개폐 연출 장치를 겸한다.
- 방과 방 사이 빈 공간은 전부 진입 불가 밀폐 구역(기계·배관이 찬 죽은 공간). 함선이 플레이 가능 영역보다 커 보이게 한다.
- 페이크 통로: 지름길처럼 보이지만 붕괴·감압으로 중간에 막히는 길. "지도는 거짓말한다" 규칙을 만든다. 모든 막다른 길 끝에는 반드시 보상(탄약 캐시 또는 서사)이 있다.

### 6.2 방 목록

| 공간 | 위치 | 역할 |
|---|---|---|
| 승무원 숙소 | 좌현 선수 | 시작 지점. 이동·사격 튜토리얼 |
| 조종부 | 선수 | 진입 불가. 배경 설정용 |
| 중앙 로비 | 함선 중앙 | 허브 교차로. 안내 단말, 벤치. 세 경로가 모이는 대피 집결지 |
| 탈출 갤러리 | 좌현 외벽 | 사출 베이 6개(5개 사출됨, 1개 잔여)가 늘어선 좁고 긴 공간. 에너지 슬롯 콘솔. 사출관은 선체 외벽을 관통 |
| 수경재배 정원 | 우현 선수 쪽 | 팩 ②. 풀과 나무가 자라는 대비 공간. 매복 전투 |
| 식당 | 우현 중단 | 경유 공간. 첫 조우. 방문 회차마다 상태 변화 |
| 의무실 | 우현 중단 | 경유 공간. 전투 없음, 환경 서사 전용 |
| 창고 | 중앙 하단 | 경유 공간. 탄약 보급 |
| 화물칸 | 우현 선미 쪽 | 팩 ③. 계단식 컨테이너 + 상부 플랫폼. 최대 규모 웨이브 |
| 기관실 | 선미 전폭 | 팩 ①. 원자로·기계 장비. 어둠 속 전투 학습 |

### 6.3 경로

- 경로 1 (기관실, 팩 ①): 로비 → 남쪽 통로 → 창고(탄약) 관통 → 두 번 꺾여 기관실. 첫 목표를 선미 끝에 두어 복도 전체를 한 번 종단하며 함선의 크기를 몸으로 익히게 한다.
- 경로 2 (정원, 팩 ②): 로비 → 북쪽 통로 → 식당(첫 조우) 관통 → 정원. 귀환은 팩 회수 시 개방되는 지름길(아래 6.4) 이용 — 식당을 건너뛰고 로비 직행.
- 경로 3 (화물칸, 팩 ③): 로비 → 식당 하단 출구 → 의무실 관통 → 지그재그 통로 → 화물칸. 회수 후 화물칸 하단 덕트로 기관실 지붕에 낙하, 아는 길로 귀환.
- 튜토리얼 경로: 숙소 → 자동문 2개를 지나는 통로 → 로비.

### 6.4 페이크 통로 및 이벤트 개방

| 통로 | 상태 | 끝의 보상 |
|---|---|---|
| 선수 횡단 통로 (숙소↔정원 직통처럼 보임) | 중간 붕괴 | 숙소 쪽 구간에 탄약 캐시. 게임 최초의 막힌 길 — 규칙 학습용 |
| 식당 위 횡단 통로 (정원 경로↔튜토리얼 통로) | 격벽 잠김 → 팩 ② 회수 시 파손 개방 | 정원 귀환 지름길로 전환 |
| 창고 오른쪽 통로 (창고↔화물칸 방향) | 끝 붕괴 | 탄약 캐시 |
| 화물칸 왼쪽 통로 | 끝 감압 | 탄약 캐시 |

### 6.5 교전 마디

통로 꺾임 3곳(튜토리얼 통로 상단 코너, 기관실 경로 하단 코너, 화물칸 경로 하단 코너)에 통로 폭 2배의 넓은 구간을 둔다. 각 경로당 하나씩 — "좁은 통로 → 넓은 마디에서 교전 → 다시 좁아짐" 리듬을 만든다. 측면 이동이 가능한 유일한 통로 구간.

## 7. 침몰 게이지

에너지팩을 슬롯에 장착할 때마다 함선 전체 상태가 한 단계 악화된다. 조명·상태 변화는 에셋이 아니라 코드라 용량이 거의 들지 않으며, 허브 앤 스포크 구조의 백트래킹 지루함을 해결하는 핵심 장치다.

| 단계 | 트리거 | 변화 |
|---|---|---|
| 0 | 시작 | 정상(이지만 이미 어두운) 조명 |
| 1 | 팩 ① 장착 | 비상등 전환 — 전 구역 붉은 조명, 통로 일부 폐쇄 |
| 2 | 팩 ② 장착 | 선체 기울기, 스파크·증기, 정원 지름길 개방 |
| 3 | 팩 ③ 장착 | 로비 침입당함 — 안전지대 상실, 카운트다운 시작 |

## 8. 파트너 로봇

기능 세 가지로 존재감을 만든다:

1. 내비게이션 — 다음 에너지팩 위치와 경로 안내. 한 번 확인한 붕괴·감압 지점은 기억해서 다시는 그쪽으로 안내하지 않는다(미로 좌절 방지의 핵심 규칙).
2. 광원 — 로봇의 라이트가 플레이어 손전등보다 넓다. 로봇과 떨어질수록 어두워지는 구조가 공포를 만든다.
3. 문 해킹 — 잠긴 구역은 로봇이 열어야 한다. 해킹하는 동안 플레이어가 방어하는 디펜스 구간이 자연스럽게 생기며, 각 팩 회수 지점의 전투 템플릿("웨이브 방어 → 획득 → 귀환")이 여기서 나온다.

## 9. 전투

- 적: 기본 1종 + 크기/색 변형 1종. 정원 매복형은 같은 메시에 웅크린 대기 애니메이션만 추가.
- 무기: 1종.
- 탄약 경제: 상시 보급처는 창고(경로 1) 하나. 나머지는 막다른 길 3곳의 탄약 캐시. 페이크 통로 탐색 보상과 보급 문제를 한 번에 해결하는 배치.
- 전투 공간: 방 = 주 전투, 교전 마디 = 통로 전투, 자동문 구간 = 전투의 단위 구획.

### 팩 회수 연출 (방마다 다르게)

| 방 | 연출 |
|---|---|
| 기관실 (①) | 팩이 예비 발전기에 꽂혀 있음. 뽑는 순간 구역 전체 소등 — 어둠 속 귀환 |
| 정원 (②) | 팩이 관개 시스템 전원. 뽑으면 스프링클러 오작동으로 시야 방해, 매복 발동. 동시에 귀환 지름길 격벽 파손 개방 |
| 화물칸 (③) | 팩이 계단식 컨테이너 위 상부 플랫폼에 있음. 최대 규모 웨이브 방어 후 획득, 덕트로 탈출 |

## 10. 피날레

세 번째 팩을 갤러리 슬롯에 꽂는 순간 사출 시퀀스 시작 — 즉시 출발하지 않고 60~90초 카운트다운. 로비가 뚫려 적이 몰려오고, 플레이어는 로비에서 갤러리로 후퇴하며 싸우는 최종 방어전을 치른다(로비-갤러리 2단 방어선 구도). 카운트다운 종료 시 캡슐 탑승 → 사출 → 멀어지는 함선을 보여주며 종료.

## 11. 식당 상태 변화 규칙

플레이어는 식당을 총 2회 통과한다(경로 2 진입 시, 경로 3 진입 시). 회차별 상태:

- 1회차: 첫 조우 전투. 뒤집힌 테이블이 엄폐물.
- 2회차: 시체가 사라져 있다. 아무 일도 일어나지 않는다 — 그 정적이 연출이다.

## 12. 기술 방향 및 에셋 예산

아래 수치는 추정치다. 실제로는 엔진/런타임 크기를 먼저 확정한 뒤 남는 용량에서 역산해야 한다.

- 지오메트리: 모듈식 복도 키트 8~10개 메시(직선·코너·T자·문틀·격벽·교전 마디)를 전 구역 재사용. 구역별 차이는 조명 색과 프랍 배치로만.
- 렌더링: 텍스처 없이 버텍스 컬러 + 다이나믹/베이크 조명. 벽·바닥의 발광 라이트 스트립과 홀로그램 표지는 이미시브(unlit) 지오메트리로 처리 — 조명 계산 없이 슬릭 SF 룩을 만드는 최저비용 수단이며, 침몰 게이지의 단계 변화(정상 청백색 → 비상 적색 → 소등)도 이 스트립의 색·온오프 전환만으로 표현한다. 짙은 안개로 드로우 디스턴스 제한. 격벽 자동문 = 구간 단위 컬링 경계.
- 프랍: 에너지팩, 슬롯 콘솔, 사출 베이 해치, 로봇, 무기, 식물 십자 평면 2~3종(인스턴싱), 화물 컨테이너 1종, 테이블·침대·벤치 등 소형 프랍 소수.
- 수직 이동: 점프·클라이밍 없음. 화물칸은 계단식 컨테이너로 걸어 오른다(컨트롤러·충돌 코드 최소화).
- 사운드: 선체 삐걱임 루프 1개 + 총성·피격·자동문·로봇 비프 등 짧은 효과음. 절차 생성 또는 초저비트레이트.

## 13. 리스크

1. (최우선, 미해결) 피날레 웨이브의 동시 적 개체 수 — 성능과 코드 크기를 동시에 소모. "몰려오는" 느낌이 몇 마리에서 성립하는지는 지도가 아니라 프로토타입에서만 검증 가능. 이 수치가 설계 전체의 성립 조건.
2. 1.44MB 총량 — 엔진/런타임 확정 전까지 모든 에셋 예산은 가정.
3. 미로 좌절 — 로봇의 막힌 길 기억 규칙과 막다른 길 보상으로 방어. 플레이테스트에서 확인 필요.

## 14. 확정 전 검증 체크리스트 (지도 최종 확정 시 수행)

- 경로별 전수 워크스루: 문 개수, 교전 지점, 보급 지점, 예상 소요 시간 표
- 침몰 게이지 단계별 막힘 검사: 폐쇄되는 문 때문에 진행 불능이 되는 조합이 없는지
- 탄약 수지 계산: 경로별 획득 가능 탄약 vs 예상 소모량
- 페이크 통로 4곳의 보상 도달 가능성 재확인

## 15. 변경 이력 (설계 결정 요약)

- v1→v2: 배경을 양수발전소에서 우주 함선으로 교체. 5구역을 3구역으로 압축, 팩 5개→3개(슬롯 6개 중 3개 기점등 설정으로 서사 유지)
- v3: 방 밀집 배치를 폐기 — 좁고 긴 자동문 통로 중심 구조로 전환
- v4: 허브를 중앙 로비(교차로)와 탈출 갤러리(사출 베이 6개)로 분리. 페이크 통로 도입
- v5: 갤러리를 좌현 외벽으로 이동(사출 방향 논리). 다분야 검증 수행
- v6: 검증 반영 — 정원 귀환 지름길, 교전 마디 3곳, 탄약 캐시 3곳, 화물칸 계단식 적재
